`elements-of-style.md` is copied verbatim. It is William Strunk Jr.'s
*The Elements of Style* (1918), public domain, from Project Gutenberg #37134.

The upstream repository has no `LICENSE` file. Its `package.json` and README
declare the text public domain. The `SKILL.md` in this directory is a local
adaptation written for this repository, not a copy of the upstream wrapper.
It points at the verbatim text and preserves the upstream attribution.

Refresh the reference with `scripts/update-writing-skills.sh`. The script
updates `elements-of-style.md` only and leaves the local wrapper in place.
